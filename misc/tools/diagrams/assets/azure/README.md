# Azure diagram assets

These Microsoft product icons come from the `img/lib/azure2/` library bundled with draw.io Desktop 32.6.1. The SVG bytes are unchanged and are embedded in the editable deployment example.

| Asset | Library path |
| --- | --- |
| `Virtual_Machine.svg` | `compute/Virtual_Machine.svg` |
| `Storage_Accounts.svg` | `storage/Storage_Accounts.svg` |
| `Azure_Database_PostgreSQL_Server.svg` | `databases/Azure_Database_PostgreSQL_Server.svg` |
| `Key_Vaults.svg` | `security/Key_Vaults.svg` |
| `Monitor.svg` | `management_governance/Monitor.svg` |

Microsoft's [Azure architecture icon terms](https://learn.microsoft.com/en-us/azure/architecture/icons#icon-terms) govern these assets. They permit use in architecture diagrams, training materials, and documentation. Preserve the icons' appearance and proportions, and use them for the corresponding Microsoft products. The [diagram guide](../../../../../docs/Diagram-Guide.md) defines their placement and size.
